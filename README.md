# AgentBridge 연구협업 보완 매칭 추가 시연본

기존 `agentbridge.kr` 최종본의 연구협업 흐름을 바탕으로 만든 별도 공개 시연 사이트입니다. 빌드 과정 없이 정적 파일만으로 동작하며, 사용자가 공고를 고르고 자신의 역할과 보완 후보를 직접 검토할 수 있습니다.

## 시연 흐름

1. 실제 공개 공고 3건 중 하나를 선택합니다.
2. 요구역량마다 `내가 담당`, `공동 담당`, `협업자 필요`, `미정` 중 하나를 정합니다.
3. 공고에 명시된 요구와 해석을 통해 도출한 요구를 구분해 확인하고, 현재 역량 공백과 합성 후보의 연구수행 근거를 비교합니다.
4. 후보를 최대 2명까지 선택하고 팀 충족 상태를 확인합니다.
5. 공고·역할·후보·팀 상태를 Markdown 파일로 내려받습니다.

역할을 바꾸면 이전 후보 선택이 초기화됩니다. 같은 탭에서 새로고침한 선택 상태는 `sessionStorage`에만 유지되고, 전체 초기화 버튼으로 삭제할 수 있습니다.

## 포함 공고 ID

- `space-nasa-roses25-apra`
- `space-kasa-discovered-B000000003393Rb8lK2`
- `space-kari-discovered-18434-t1`

후보는 원본 공개 시연용 합성 연구자 50명을 사용합니다. 역량, 작업유형, 직접·전이 구분, 근거 출처, 공동연구자 연결은 원본 필드를 기계적으로 변환했고, 표시 이름만 `합성 연구자 R-xxx` 형식으로 통일했습니다. 화면과 소스에는 실명, 이메일, 전화번호 등 개인 식별 정보를 포함하지 않습니다.

## 로컬 실행

정적 파일의 ESM import가 동작하도록 이 디렉터리를 HTTP 서버로 열어야 합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`에 접속합니다. 별도 의존성 설치나 빌드가 필요하지 않습니다.

## 테스트

```bash
node --test
```

테스트는 매칭 규칙, 역할 변경 시 선택 초기화, 후보 2명 제한, 세션 상태 복구, 공개 데이터 범위와 정제본 SHA-256, Markdown 생성 결과를 확인합니다. 테스트는 이 디렉터리 밖의 원본 저장소나 비공개 파일을 읽지 않으므로 공개 저장소만 복제해도 동일하게 실행됩니다.

## 파일 구성

- `index.html`: 시연 화면 구조
- `styles.css`: 반응형 화면과 접근성 스타일
- `data.js`: 공개 공고·RFP 3건과 합성 후보 50명의 기계 변환 데이터
- `matching.js`: 직접·전이·공동연구자·AI 추론 상한을 반영한 보완 매칭
- `state.js`: 상태 변경과 `sessionStorage` 처리
- `report.js`: Markdown 결과 생성·다운로드
- `app.js`: 화면 렌더링과 사용자 상호작용
- `tests/`: Node 기본 테스트 러너용 검증 코드
